KITKAT CLIENT — исходный проект
Minecraft Java 1.21.4 / Fabric / Java 21

Что уже заложено:
- ClickGUI из шести колонок в стиле скриншота.
- Тёмные полупрозрачные панели и фиолетовые стеклянные блики.
- Переключатели реализованных визуальных/QoL-модулей.
- HUD, FPS, координаты, AutoSprint, AutoJump и Fullbright.
- Открытие меню клавишей Right Shift.

Важно:
- Это исходный проект, не готовый .jar.
- В этой версии Combat-модули и сетевые/пакетные функции показаны как недоступные заглушки.
- Нет обхода античита, автоматических атак или эксплуатации серверов.
- Некоторые пункты интерфейса пока являются заглушками следующего этапа.
- Сборка требует установленного JDK 21 и доступа Gradle к Maven-репозиториям.

Сборка:
1. Открой папку проекта в IntelliJ IDEA.
2. Укажи JDK 21.
3. Дождись синхронизации Gradle.
4. Запусти Gradle task: build.
5. Готовый мод будет в build/libs/.
Установка:
Скопируй kitkat-client-1.0.0.jar в .minecraft/mods вместе с Fabric API.
Открыть меню: Right Shift.

Тема интерфейса: KitKat — красный цвет обёртки, шоколадно-коричневые стеклянные панели, кремовые надписи и оттенки вафли.
